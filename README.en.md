# Impact Evaluation Framework — English

A reusable technical framework for structuring outcome and impact evaluations of projects, programs, and social initiatives.

## Workflow

**Understanding → Model → Indicators → Instruments → Data → Analysis → Management → Final Evaluation**

## Purpose

- structure objectives and expected outcomes;
- distinguish activities, outputs, outcomes, and impacts;
- build indicator matrices;
- plan data-collection instruments and routines;
- organize data architecture and quality controls;
- support analysis, dashboards, and reporting;
- document requirements, assumptions, and limitations.

## Privacy

This repository uses only generic structures and fictional or sanitized data. Do not publish personal data, confidential institutional information, contacts, credentials, or client-identifying information without authorization.
