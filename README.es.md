# Impact Evaluation Framework — Español

Marco técnico y reutilizable para estructurar evaluaciones de resultados e impacto de proyectos, programas e iniciativas sociales.

## Flujo

**Comprensión → Modelo → Indicadores → Instrumentos → Datos → Análisis → Gestión → Evaluación final**

## Propósito

- estructurar objetivos y resultados esperados;
- diferenciar actividades, productos, resultados e impactos;
- construir matrices de indicadores;
- planificar instrumentos y rutinas de recopilación;
- organizar la arquitectura y la calidad de los datos;
- apoyar análisis, paneles y informes;
- documentar requisitos, supuestos y limitaciones.

## Privacidad

Este repositorio utiliza únicamente estructuras genéricas y datos ficticios o sanitizados. No publique datos personales, información institucional confidencial, contactos, credenciales ni información que permita identificar clientes sin autorización.
