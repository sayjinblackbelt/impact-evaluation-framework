# Examples

Esta pasta deve conter somente exemplos sintéticos e genéricos.

## Exemplos permitidos

- modelos lógicos fictícios;
- matrizes de indicadores demonstrativas;
- bases de dados sintéticas;
- exemplos de dashboards sem dados reais;
- estudos de caso totalmente fictícios.

## Exemplos proibidos

- nomes reais de organizações, clientes, contratantes ou solicitantes sem autorização;
- nomes reais de participantes ou colaboradores;
- dados de contato;
- resultados reais identificáveis;
- documentos internos;
- qualquer combinação de campos que permita reidentificação.

Quando um caso profissional gerar um novo aprendizado para o framework, transformar primeiro a experiência em um padrão genérico e sanitizado.
