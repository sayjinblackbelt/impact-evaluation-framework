# Data

Esta pasta é reservada a dados de demonstração.

## Regra de publicação

Somente dados fictícios, sintéticos ou devidamente sanitizados podem ser incluídos neste diretório.

Nunca publicar dados pessoais, identificáveis, sensíveis, institucionais restritos ou dados brutos de clientes/projetos sem autorização formal.

## Dados sintéticos

Quando exemplos forem necessários, utilizar identificadores genéricos como `P001`, `P002`, `U001` e categorias fictícias que não permitam reidentificação.
