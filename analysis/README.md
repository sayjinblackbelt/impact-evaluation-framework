# Analysis

Espaço para documentação de métodos de análise, regras de interpretação e exemplos sintéticos.

## Princípios

- começar pela pergunta de avaliação;
- descrever o dado antes de interpretá-lo;
- explicitar denominadores e métricas;
- separar associação de causalidade;
- registrar limitações;
- evitar conclusões além do que o desenho permite sustentar.

## Possíveis camadas

1. Qualidade e completude;
2. Estatística descritiva;
3. Comparações temporais;
4. Segmentações relevantes;
5. Associação entre variáveis;
6. Métodos inferenciais ou causais, quando metodologicamente justificáveis.
