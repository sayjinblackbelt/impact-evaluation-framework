# Matriz de Indicadores

A matriz é o principal elo entre metodologia, coleta, dados e análise.

## Campos recomendados

| Campo | Finalidade |
|---|---|
| Público | Define quem é avaliado |
| Eixo/dimensão | Organiza o indicador |
| Objetivo | O que se pretende avaliar |
| Resultado esperado | Mudança esperada |
| Indicador | Evidência observável |
| Métrica | Forma de quantificação |
| Fonte | Origem do dado |
| Instrumento | Como o dado será coletado |
| Periodicidade | Quando será medido |
| Responsável | Quem coleta/valida |
| Método de análise | Como será interpretado |
| Visualização | Como será apresentado |

## Critérios de qualidade

Um indicador deve ser:

- relevante para o objetivo;
- compreensível;
- mensurável ou observável;
- viável de coletar;
- rastreável à fonte;
- comparável quando necessário;
- interpretável;
- proporcional ao esforço de coleta.

## Estrutura de desenvolvimento

**Objetivo → Resultado esperado → Dimensão → Indicador → Métrica → Fonte → Instrumento → Análise → Visualização**

A matriz final deve ser validada depois da compreensão do contexto e dos materiais metodológicos disponíveis.
