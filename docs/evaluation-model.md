# Modelo de Avaliação

## Modelo lógico

O modelo lógico conecta a intervenção às mudanças esperadas:

**Recursos → Atividades → Produtos → Resultados → Impactos**

Cada nível responde a uma pergunta diferente.

| Nível | Pergunta |
|---|---|
| Recursos | O que foi disponibilizado? |
| Atividades | O que foi realizado? |
| Produtos | O que foi entregue ou produzido? |
| Resultados | O que mudou nos participantes, equipes ou contexto? |
| Impactos | Que mudança mais ampla se pretende compreender? |

## Teoria de mudança

Quando necessário, documentar a cadeia causal esperada:

**Intervenção → mecanismo de mudança → resultado esperado → impacto esperado**

Também registrar premissas, fatores externos e limitações de atribuição.

## Avaliação de impacto

O termo impacto não deve ser tratado como sinônimo de satisfação, atividade realizada ou resultado imediato. Antes de definir o método, deve-se esclarecer qual conceito de impacto está sendo utilizado.

Perguntas fundamentais:

- Qual mudança representa impacto?
- Em qual população?
- Em qual período?
- Existe linha de base?
- Existem dados históricos comparáveis?
- Existe possibilidade de comparação?
- Há hipótese causal explícita?
- Qual nível de atribuição é tecnicamente defensável?

## Regra de decisão

Se os dados e o desenho permitirem apenas descrever resultados, o produto deve ser apresentado como avaliação de resultados/desempenho, sem extrapolar conclusões causais.

Se houver desenho, dados e comparação adequados, pode-se avançar para métodos de avaliação de impacto com maior rigor inferencial.
