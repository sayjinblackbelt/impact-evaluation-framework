# Dashboard

## Objetivo

Organizar visualizações para acompanhamento e tomada de decisão.

## Princípios

O dashboard é uma camada de visualização e gestão. A construção deve acontecer depois da definição da metodologia, indicadores e arquitetura de dados.

## Componentes possíveis

- indicadores principais;
- evolução temporal;
- filtros por público, período e dimensão;
- comparações relevantes;
- alertas ou pontos de atenção;
- detalhamento sob demanda;
- notas metodológicas e limitações.

## Requisitos a validar

Antes de escolher uma ferramenta, definir:

- usuários;
- nível de acesso;
- frequência de atualização;
- volume de dados;
- fontes;
- filtros;
- necessidade de histórico;
- necessidade de exportação;
- responsabilidade de manutenção.

A ferramenta de BI deve ser escolhida depois desses requisitos.
