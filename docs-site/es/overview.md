# Visión general

El **Impact Evaluation Framework** organiza la evaluación como un sistema integrado, desde la comprensión del problema hasta la producción de evidencias para la toma de decisiones.

## Flujo

Comprensión → Modelo → Indicadores → Instrumentos → Datos → Análisis → Gestión → Evaluación final.

## Objetivo

Apoyar a equipos en el diseño de evaluaciones de proyectos, programas e iniciativas sociales, sin depender inicialmente de una herramienta tecnológica específica.

## Principios

- Comprender antes de medir.
- Medir lo que importa para la decisión.
- Diferenciar actividad, producto, resultado e impacto.
- Respetar las limitaciones de los datos.
- Priorizar calidad y trazabilidad.
- Hacer que la tecnología sirva a la metodología.
- Proteger la privacidad y la gobernanza de datos.
