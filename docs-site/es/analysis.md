# Análisis

El análisis transforma los datos en evidencias interpretables.

## Capas

- descripción de los datos;
- evolución temporal;
- comparación entre grupos o períodos cuando corresponda;
- identificación de patrones;
- interpretación según el modelo de evaluación;
- limitaciones;
- traducción de hallazgos en decisiones y recomendaciones.

No confundir asociación, cambio observado y causalidad.
