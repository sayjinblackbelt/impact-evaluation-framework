# Instrumentos y recopilación

Los instrumentos deben derivarse de las preguntas de evaluación y de los indicadores.

## Planificación

Definir qué se medirá, quién responde, quién aplica el instrumento, cuándo y dónde se recopilan los datos, cómo se registran y quién los valida.

## Rutina

Aplicación → Registro → Validación → Consolidación → Tratamiento → Análisis.

Pueden utilizarse cuestionarios, entrevistas, observación, registros administrativos u otras fuentes adecuadas al contexto.
