# Dashboard y BI

El dashboard es una capa de visualización y gestión. La herramienta debe elegirse después de definir la metodología, los indicadores y la arquitectura de datos.

## Funciones

- monitorear indicadores;
- filtrar por dimensiones y públicos;
- visualizar tendencias en el tiempo;
- apoyar decisiones tácticas y estratégicas;
- comunicar resultados con claridad.

## Principio

**Metodología → datos → análisis → visualización.**

El BI no sustituye la evaluación.
