# Requisitos y dimensionamiento

Antes de definir una solución, identificar los requisitos que determinan alcance, plazo y esfuerzo.

## Preguntas clave

- ¿Qué debe demostrar la evaluación?
- ¿Quién será evaluado y cuál es el volumen?
- ¿Qué período se analizará?
- ¿Qué materiales y datos ya existen?
- ¿Existe una línea de base o historial comparable?
- ¿Quién recopila, valida y analiza los datos?
- ¿Qué infraestructura tecnológica existe?
- ¿Quién utilizará dashboards e informes?

## Dimensionamiento

**Alcance + tiempo + volumen + complejidad + responsabilidades + tecnología.**

La propuesta técnica y financiera debe construirse después del diagnóstico.
