# Indicadores

La matriz de indicadores conecta objetivos, resultados esperados, evidencias, métricas, fuentes, instrumentos, periodicidad, responsabilidades, análisis y visualización.

## Estructura mínima

| Campo | Función |
|---|---|
| Público | Define quién es evaluado |
| Dimensión | Aspecto específico |
| Objetivo | Qué evaluar |
| Resultado esperado | Cambio esperado |
| Indicador | Evidencia observable |
| Métrica | Cómo cuantificar |
| Fuente | Origen de los datos |
| Instrumento | Cómo recopilar |
| Periodicidad | Cuándo medir |
| Método de análisis | Cómo interpretar |
| Visualización | Cómo comunicar |

Utiliza la plantilla disponible en `indicators/`.
