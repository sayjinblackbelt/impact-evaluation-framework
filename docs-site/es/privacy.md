# Datos y privacidad

Este framework público no debe contener datos personales, sensibles o información institucional confidencial.

## Permitido

- datos sintéticos;
- ejemplos ficticios;
- estructuras genéricas;
- datos correctamente anonimizados o sanitizados cuando corresponda.

## No publicar

- nombres o contactos de participantes;
- documentos o identificadores personales;
- datos brutos de clientes u organizaciones;
- credenciales y claves;
- información que permita identificar un proyecto real sin autorización.

La sanitización es una etapa obligatoria antes de publicar.
