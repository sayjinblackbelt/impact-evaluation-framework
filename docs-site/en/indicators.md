# Indicators

The indicator matrix connects objectives, expected outcomes, evidence, metrics, sources, instruments, frequency, responsibility, analysis and visualization.

## Minimum structure

| Field | Purpose |
|---|---|
| Audience | Defines who is evaluated |
| Dimension | Specific aspect |
| Objective | What to evaluate |
| Expected outcome | Expected change |
| Indicator | Observable evidence |
| Metric | How to quantify |
| Source | Data origin |
| Instrument | How to collect |
| Frequency | When to measure |
| Analysis method | How to interpret |
| Visualization | How to communicate |

Use the template in `indicators/`.
