# Methodology

Evaluation should be designed before selecting forms, databases, dashboards or statistical methods.

## Layers

1. Context and problem understanding.
2. Logic model and theory of change.
3. Dimensions and indicators.
4. Instruments and collection routine.
5. Data architecture and quality.
6. Analysis and interpretation.
7. Visualization and management support.
8. Final evaluation and evidence synthesis.

## Logic model

Resources → Activities → Outputs → Outcomes → Impacts.

Each layer should make clear what can be concluded and what its limitations are.
