# Dados e privacidade

Este framework público não deve conter dados pessoais, sensíveis ou informações institucionais confidenciais.

## Permitido

- dados sintéticos;
- exemplos fictícios;
- estruturas genéricas;
- dados devidamente anonimizados ou sanitizados quando apropriado.

## Não publicar

- nomes e contatos de participantes;
- documentos e identificadores pessoais;
- dados brutos de clientes ou organizações;
- credenciais e chaves;
- informações que permitam identificar um projeto real sem autorização.

A sanitização deve ser tratada como etapa obrigatória antes da publicação.
