## O que um dashboard deve responder

<div class="interactive-grid"><div class="interactive-card"><h3>👀 O que está acontecendo?</h3><p>Indicadores atuais, distribuição dos resultados e sinais que merecem atenção.</p></div><div class="interactive-card"><h3>📈 O que mudou?</h3><p>Comparações entre períodos, tendências e diferenças relevantes.</p></div><div class="interactive-card"><h3>🔎 Onde está a diferença?</h3><p>Filtros e cruzamentos para localizar públicos, dimensões ou contextos com comportamentos distintos.</p></div><div class="interactive-card"><h3>🧭 O que fazer agora?</h3><p>O painel deve apoiar decisões; não apenas apresentar gráficos.</p></div></div>

## Funções

- acompanhar indicadores;
- filtrar por dimensões e públicos;
- visualizar evolução temporal;
- apoiar decisões táticas e estratégicas;
- comunicar resultados de forma clara.

## Princípio

**Metodologia → dados → análise → visualização.**

O BI não substitui a avaliação. Ele torna a evidência mais acessível para quem precisa interpretá-la e tomar decisões.

<div class="callout"><strong>Importante:</strong> esta é uma demonstração visual com dados sintéticos. A implementação real deve ser definida somente depois da metodologia, matriz de indicadores, arquitetura de dados e requisitos de gestão estarem validados.</div>
