# Dashboard e BI

O dashboard é uma camada de visualização e gestão. A ferramenta deve ser escolhida depois da definição da metodologia, indicadores e arquitetura de dados.

## Funções

- acompanhar indicadores;
- filtrar por dimensões e públicos;
- visualizar evolução temporal;
- apoiar decisões táticas e estratégicas;
- comunicar resultados de forma clara.

## Princípio

**Metodologia → dados → análise → visualização.**

O BI não substitui a avaliação.
