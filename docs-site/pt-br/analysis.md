# Análise

A análise transforma dados em evidências interpretáveis.

## Camadas

- descrição dos dados;
- evolução temporal;
- comparação entre grupos ou períodos, quando adequada;
- identificação de padrões;
- interpretação à luz do modelo de avaliação;
- registro de limitações;
- tradução dos achados em decisões e recomendações.

Não confundir associação, mudança observada e causalidade.
