# Visão geral

O **Impact Evaluation Framework** organiza a avaliação como um sistema integrado, da compreensão do problema à produção de evidências para decisão.

## Fluxo

Compreensão → Modelo → Indicadores → Instrumentos → Dados → Análise → Gestão → Avaliação final.

## Objetivo

Apoiar equipes na estruturação de avaliações de projetos, programas e iniciativas sociais, sem depender inicialmente de uma ferramenta específica.

## Princípios

- Conhecer antes de medir.
- Medir o que importa para a decisão.
- Diferenciar atividade, produto, resultado e impacto.
- Respeitar os limites dos dados.
- Priorizar qualidade e rastreabilidade.
- Fazer a tecnologia servir à metodologia.
- Preservar privacidade e governança.
