# Indicadores

A matriz de indicadores conecta objetivo, resultado esperado, evidência, métrica, fonte, instrumento, periodicidade, responsabilidade, análise e visualização.

## Estrutura mínima

| Campo | Função |
|---|---|
| Público | Define quem é avaliado |
| Dimensão | Aspecto específico |
| Objetivo | O que avaliar |
| Resultado esperado | Mudança esperada |
| Indicador | Evidência observável |
| Métrica | Como quantificar |
| Fonte | Origem dos dados |
| Instrumento | Como coletar |
| Periodicidade | Quando medir |
| Método de análise | Como interpretar |
| Visualização | Como comunicar |

Use o template disponível em `indicators/`.
