# Modelo de avaliação

## Cadeia lógica

**Recursos → Atividades → Produtos → Resultados → Impactos**

O modelo lógico organiza a relação entre o que é investido, o que é realizado, o que é produzido e as mudanças esperadas.

## Teoria de mudança

Explicita como e por que determinadas atividades devem produzir resultados e impactos, incluindo premissas e condições.

## Cuidado metodológico

A existência de uma mudança observada não significa, por si só, que ela foi causada pelo programa. O nível de evidência deve ser compatível com o desenho da avaliação e com os dados disponíveis.
