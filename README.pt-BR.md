# Impact Evaluation Framework — Português

Framework técnico e reutilizável para estruturar avaliações de resultados e impacto em projetos, programas e iniciativas sociais.

## Fluxo

**Compreensão → Modelo → Indicadores → Instrumentos → Dados → Análise → Gestão → Avaliação final**

## Para que serve

- estruturar objetivos e resultados esperados;
- diferenciar atividades, produtos, resultados e impactos;
- construir matrizes de indicadores;
- planejar instrumentos e rotinas de coleta;
- organizar arquitetura e qualidade dos dados;
- apoiar análise, dashboards e relatórios;
- documentar requisitos, premissas e limitações.

## Privacidade

Este repositório utiliza somente estruturas genéricas e dados fictícios ou sanitizados. Não publique dados pessoais, dados institucionais confidenciais, contatos, credenciais ou informações que identifiquem clientes sem autorização.
