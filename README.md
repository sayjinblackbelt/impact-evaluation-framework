# Impact Evaluation Framework

Framework técnico para estruturar avaliações de resultados e impacto de projetos, programas e iniciativas sociais.

🌐 **Documentação online:** [GitHub Pages](https://sayjinblackbelt.github.io/impact-evaluation-framework/)

## Objetivo

Este repositório reúne modelos, estruturas e referências práticas para apoiar um processo completo de avaliação:

**Compreensão → Modelo → Indicadores → Instrumentos → Dados → Análise → Gestão → Avaliação final**

A proposta é organizar a avaliação como um sistema integrado, conectando metodologia, coleta, qualidade dos dados, análise, visualização e tomada de decisão.

## Componentes

- modelo lógico e teoria de mudança;
- matriz de indicadores;
- definição de dimensões, métricas e fontes;
- instrumentos e rotinas de coleta;
- arquitetura de dados;
- validação e qualidade dos dados;
- análise e interpretação;
- dashboards e visualização gerencial;
- relatórios periódicos;
- avaliação final e síntese de evidências;
- levantamento de requisitos e dimensionamento do projeto.

## Princípios

1. Conhecer antes de medir.
2. Medir o que é relevante para a decisão.
3. Diferenciar atividade, produto, resultado e impacto.
4. Não atribuir ao indicador mais do que os dados permitem concluir.
5. Priorizar rastreabilidade e qualidade dos dados.
6. Fazer a tecnologia servir à metodologia.
7. Documentar decisões, premissas e limitações.
8. Preservar privacidade, segurança e governança dos dados.

## Dados e privacidade

Este repositório **não contém dados pessoais, identificáveis ou informações institucionais sensíveis**.

Os exemplos e conjuntos de dados disponibilizados devem ser fictícios, anonimizados ou sanitizados exclusivamente para fins de demonstração, desenvolvimento e documentação.

Não devem ser publicados neste repositório:

- nomes de participantes, estudantes, jovens, responsáveis ou colaboradores;
- telefones, e-mails, documentos ou outros identificadores pessoais;
- informações pessoais sensíveis;
- dados brutos de organizações contratantes, empregadores ou solicitantes;
- documentos institucionais não autorizados para publicação;
- credenciais, tokens, chaves de API ou configurações privadas;
- nomes ou identificadores que permitam relacionar este framework a um cliente específico sem autorização.

## Escopo público

Este projeto deve permanecer como um **framework genérico e reutilizável**. Experiências profissionais podem orientar sua evolução, mas informações específicas de projetos, organizações ou clientes devem ser convertidas em estruturas genéricas antes de qualquer publicação.

## Evolução

O repositório será atualizado conforme o framework evoluir na prática. Novas versões podem incluir modelos de indicadores, exemplos sintéticos, instrumentos genéricos, estruturas de dados, rotinas de análise e documentação técnica.

## Status

Em desenvolvimento contínuo.

> Este projeto é um framework técnico e não representa, por si só, uma avaliação de impacto de uma organização específica.
